# 我的护肤柜

手机上用的护肤品管理网页：记录有哪些护肤品、使用状态、保质期，以及早晚护肤流程。

- 纯 HTML / CSS / JS，不需要安装依赖、不需要构建
- 数据存在手机浏览器本地（IndexedDB），零成本、不需要登录
- 可以「添加到主屏幕」，像 App 一样全屏打开，断网也能用

## 功能

- **产品库**：名称、品牌、品类、照片、价格、购买日期、备注
- **状态**：使用中 / 囤货 / 已用完（记录回购意向）/ 弃用
- **保质期提醒**：取「未开封保质期」和「开封日 + 开封后保质期」中较早的一个，30 天内到期会显示在首页
- **早晚流程**：使用中的产品按品类自动排序
- **备份**：导出 / 导入 JSON 文件

## 本地预览

```bash
python3 -m http.server 8765
```

然后打开 http://localhost:8765
